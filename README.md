# paper-math-readings

Readings of 15 equations from AI and ML papers, written with the agent skills in
[paper-math-skills](https://github.com/slavadubrov/paper-math-skills). Each
reading explains one paper's equations for an engineer who reads code but not
research notation. It quotes where each symbol is defined, gives shapes and
roles, and works the equation through with a NumPy check whose output is pasted
in.

The readings go with the series
[Reading the Math in AI Papers](https://slavadubrov.com/blog/2026/11/03/reading-math-in-ai-papers/).

## Limits

- The readings were written and checked by agents, so they can still contain
  errors.
- The NumPy checks test the equations on small inputs. They do not reproduce
  the papers' experiments.
